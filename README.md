# URANIUM 0.1.0

Клиентский мод-оптимизатор для Minecraft 1.21.11 (Fabric).

## Сборка
1. Установи JDK 21.
2. В папке проекта выполни `gradlew build` (Windows) или `./gradlew build` (Linux/macOS).
3. Готовый jar появится в `build/libs/uranium-0.1.0.jar`.

## Установка
Положи jar в папку `mods` вместе с Fabric API.

## Модули
- Куллинг частиц и сущностей по дистанции
- Отключение теней сущностей, тумана, виньетки
- Адаптивные профили PERFORMANCE / BALANCED / QUALITY
- Троттлинг FPS в меню (по умолчанию 20 FPS)
- Ограничение FPS в свёрнутом окне
- Каркас кэша HUD (полный blit — в 0.2)

## Конфиг
`config/uranium.properties` — создаётся при первом запуске.

## Важно
Имена методов в миксинах написаны под Yarn 1.21.11. Если какой-то @Inject не найдёт цель,
в логе будет видно, какой именно — проверь сигнатуру в IDE и поправь.
